Getting started

  1. Download the companion app: AirPointer.app for macOS, or AirPointerWindows.zip for Windows, from the releases page.
  2. Open it and allow Bluetooth (on the Mac also Accessibility) when asked.
  3. Open Air Pointer on the iPhone or iPad, then either tap Pair next to the computer or scan the QR code shown on it.

The Mac app lives in the menu bar (cursor icon); the Windows app in the tray. On a Mac with a notch, the island shows the same controls.

Names and several computers

Under Settings › This iPhone you can choose the name the computer shows for this phone. Each computer keeps its own key order, hidden keys and custom shortcuts; switching computer in Computers switches its layout.

Keys and shortcuts

Settings › Keys reorders the key strip, hides the ones you don't use and adds your own: press the shortcut on the computer, then give it a name and an icon. Custom keys belong to the computer they were captured on.

Windows

Extract AirPointerWindows.zip somewhere permanent and run AirPointer.exe. Windows SmartScreen may warn about an unsigned app: More info → Run anyway.

Bluetooth on Windows needs the packaged (MSIX) build on some PCs. If the tray says “Bluetooth unavailable” or “Could not start”, the plain .exe cannot host the Bluetooth server there; use the MSIX build instead.

Updates

The companion app checks for updates once an hour: Update to x.y.z in the Mac menu bar or the Windows tray. On a Mac it replaces itself and restarts; the Accessibility permission is kept because the app is signed with the same identity.

FAQ

The cursor doesn't move.

Accessibility permission is missing: System Settings › Privacy & Security › Accessibility › enable Air Pointer. Then reopen the app.

Mission Control or spaces do nothing.

They are posted through System Events. The first time, macOS asks “Air Pointer wants to control System Events”: allow it. If you denied it, re-enable it in System Settings › Privacy & Security › Automation.

The app pauses by itself.

It pauses when you use the computer's own mouse or trackpad, and when the phone app goes to the background. Press Resume on the phone, in the menu bar, or in the island.

The phone must stay on.

iOS suspends motion updates in the background, so keep the app open with the screen on while you use it.
